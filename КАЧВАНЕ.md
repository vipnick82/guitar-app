# Качване в GitHub Pages

Всичко се прави от браузъра - не ти трябва git, командна линия или инсталации.

## 1. Ново репо

Отвори **github.com/new**

- **Repository name:** `guitar-practice`
- **Public** (задължително - Pages не работи с private в безплатния план)
- Не отмятай нищо друго (без README, без .gitignore)
- **Create repository**

## 2. Качи 6-те файла

На празната страница на репото натисни **uploading an existing file**
(или `Add file` → `Upload files`).

Пусни вътре и шестте:

```
index.html
manifest.json
sw.js
icon-180.png
icon-192.png
icon-512.png
```

Долу **Commit changes**.

> Внимавай файлът да се казва точно `index.html` - GitHub Pages търси него.

## 3. Включи Pages

Репото → **Settings** → в лявото меню **Pages**

- **Source:** `Deploy from a branch`
- **Branch:** `main`, папка `/ (root)`
- **Save**

След 1-2 минути презареди страницата - горе ще се появи зелено:

```
https://ТВОЕТО-ИМЕ.github.io/guitar-practice/
```

## 4. На телефона

1. Отвори линка в **Safari** (не в Chrome - на iOS само Safari може да добавя към началния екран)
2. Изчакай да чуеш звук веднъж - мострите се свалят и се кешират
3. Бутона **Сподели** (квадратчето със стрелката нагоре)
4. **Add to Home Screen** → **Add**

Готово. Иконата стои при другите приложения, отваря се на цял екран без адресна лента и работи офлайн.

---

## Какво е нагласено за iPhone

| | |
|---|---|
| Звук при безшумен ключ | `navigator.audioSession = 'playback'` - иначе Safari мълчи, ако страничният ключ е долу (iOS 16.4+) |
| Екранът не заспива | Wake Lock се включва при Play и се пуска при Stop |
| Челка и лентата за жестове | `viewport-fit=cover` + `env(safe-area-inset-*)` |
| Без zoom при двойно почукване | `touch-action:manipulation` |
| Офлайн | Service worker кешира страницата и всичките mp3 мостри |

## Ако нещо не тръгне

**Страницата е 404** - изчакай 2-3 минути, първият деплой се бави. Провери и че файлът е `index.html`, не `Index.html`.

**Няма звук на телефона** - вдигни страничния ключ от безшумен режим. Ако пак няма, iOS-ът ти е под 16.4 и `audioSession` не се поддържа.

**Иконата е скрийншот вместо чертежа** - изтрий я от началния екран, дръпни надолу в Safari да презаредиш и я добави пак.

**Промени не се виждат** - service worker-ът дава старата версия. В `sw.js` смени `guitar-practice-v1` на `v2`, качи го наново и презареди два пъти.

## Как да обновиш песен по-късно

Репото → цъкни на `index.html` → молива горе вдясно → редактирай → **Commit changes**.
След минута е живо и на телефона.
